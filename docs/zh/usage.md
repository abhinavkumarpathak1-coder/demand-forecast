# 使用指南

典型流程分为五步：导入数据 → 数据洞察 → 模型训练 → 需求预测 → 促销模拟。
除登录页外，所有页面都需要登录后访问。

## 1. 数据管理（`/data/`）

### 上传

* `/data/upload/` 接收 `.xlsx` 格式的销售数据与促销数据（≤ 10 MB）。
* 同一页面可下载模板，请保持列名不变。
* 上传后系统会自动清洗：去重、缺失销量补 `0`、负值截断、日期按 `YYYY-MM-DD` 解析。
* 出现新的物料号时会自动创建产品主数据（`物料号` + `物料名称` + 五级分类）。

### 浏览、调整、导出

* `/data/view/` —— 按区域、SKU、日期范围筛选，并导出当前结果到 Excel。
* `/data/adjust/` —— 直接编辑最近的销售与促销记录。
  预测值也可以在预测结果页中人工覆盖。

## 2. 数据洞察（`/insight/`）

* 选择一个或多个区域与 SKU，设定日期范围后点击「查询」。
* 两个饼图分别展示 Top-5 区域与 Top-5 SKU，点击扇区可查看对应明细。
* 折线图展示指定物料的销量趋势，支持年度、季度、月度、周度四种粒度。

## 3. 模型训练（`/model/`）

1. 选择产品层级（一级至五级分类或 SKU）与目标项目，并至少选择一个销售区域。
   未勾选的层级视为全选。
2. 点击「开始训练」。系统会对每个「区域 × 产品」组合逐个训练可用算法，
   用最后三个月做评估，剔除过拟合模型（并降复杂度重试），保留最优模型；
   若有两个以上模型训练成功，还会再做一次融合并比较。
3. `/model/results/` 列出已保存的模型，包含准确率、MAE/RMSE 以及预测与实际对比图。

执行预测时若没有可用模型，系统也会自动触发训练。

## 4. 需求预测（`/forecast/`）

1. 选择层级、产品与区域，再选择预测周期（1–24 个月，默认 12）。
2. 模型模式：
   * **自动匹配** —— 为每个组合挑选已训练的最优模型。
   * **手动选择** —— 从列表中指定某个模型（可用「刷新」重新加载）。
3. 结果页（`/forecast/results/`）包含：
   * 所选组合的预测对比图，
   * 含实际值 / 预测值 / 调整后预测值的明细表，
   * 行内编辑：点击预测值、输入新值、回车保存。
4. 点击「导出 Excel」下载明细表。

预测结果可以保存为「场景」，之后通过 `/forecast/scenario/<id>/` 重新载入。

## 5. What-If 分析（`/forecast/what-if/`）

* 选择最深层级的一个或多个分类 / SKU，以及销售区域。
* 设置「促销力度调整」（例如 `+10` 表示比当前再多投入 10%）。
* 「弹性系数」留空则自动从历史数据计算，也可手动填写；
  页面下方会展示计算公式与数据覆盖情况。
* 结果展示基线总销量、What-If 总销量、逐月对比图以及受影响区域。

## 语言切换

侧边栏底部（或登录页）的下拉框可在英文与简体中文之间切换界面语言。
选择保存在 `django_language` Cookie 中，翻页和下次登录都会保持。
详见 [i18n.md](i18n.md)。

## 使用建议

* 建议按区域分别训练：不同区域的需求规律通常不适合共用模型。
* 历史数据建议不少于 24 个月；季节类算法需要两个完整季节周期才能发挥效果。
* 间断需求（大量零值月份）可优先尝试 `croston` / `sba`。
* 导出到下游系统前，建议人工复核一遍调整后的预测值。
