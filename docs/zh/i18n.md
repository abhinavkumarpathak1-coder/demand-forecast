## 1. 概览

界面内置六种语言。

| 语言 | 代码 | 目录 |
| --- | --- | --- |
| English（默认） | `en` | `locale/en/LC_MESSAGES/django.po` |
| 中文 | `zh-hans` | `locale/zh_Hans/LC_MESSAGES/django.po` |
| Français | `fr` | `locale/fr/LC_MESSAGES/django.po` |
| Deutsch | `de` | `locale/de/LC_MESSAGES/django.po` |
| Español | `es` | `locale/es/LC_MESSAGES/django.po` |
| 日本語 | `ja` | `locale/ja/LC_MESSAGES/django.po` |

| 项目 | 取值 |
| --- | --- |
| `LANGUAGE_CODE` | `en`（可用 `DJANGO_LANGUAGE_CODE` 覆盖） |
| `LANGUAGES` | `en`、`zh-hans`、`fr`、`de`、`es`、`ja` |
| `LOCALE_PATHS` | 项目根目录的 `locale/` |
| 切换入口 | `/i18n/setlang/`（`django.views.i18n.set_language`） |
| 存储方式 | `django_language` Cookie（浏览器会话级） |
| 控件位置 | 右上角、账号信息旁边（登录页为固定右上角） |

每种语言都用**它自己的语言**显示（`English`、`中文`、`Français`、`Deutsch`、
`Español`、`日本語`），详见[切换器中的语言名称](#切换器中的语言名称)。

**源语言是中文。** 模板中使用 `{% translate "…" %}`，Python 中使用
`gettext()` / `gettext_lazy()` 包裹中文字符串，因此每条目的 `msgid` 是中文，
`locale/en` 中的 `msgstr` 才是英文。

由于 Django 在译文缺失时会回退到默认语言的目录，所以 `locale/zh_Hans` 是一份
**恒等目录**（`msgstr == msgid`）。没有它，切换到中文时仍然会显示英文。

## 2. 语言的判定顺序

`apps.core.middleware.DefaultLanguageLocaleMiddleware`（`LocaleMiddleware` 的子类，
注册在 `SessionMiddleware` 之后）依次按以下顺序判定：

1. URL 的语言前缀（本项目未启用），
2. `django_language` Cookie —— 由切换表单写入，
3. `LANGUAGE_CODE`（默认 `en`）。

浏览器请求头的 `Accept-Language` **不参与判定**，因此即便浏览器语言是中文，
默认仍然是英文。若希望恢复 Django 默认的请求头探测，可设置
`DJANGO_LANGUAGE_FROM_BROWSER=True`（即 `settings.LANGUAGE_FROM_BROWSER`）。

切换控件是 `templates/includes/language_switcher.html` 中的一个小表单，
由 `templates/base.html` 引入到主内容区右上角（已登录），
未登录时则固定在登录页右上角，向 `/i18n/setlang/` 提交 `language` 与 `next`。

Cookie 是浏览器会话级的，因此重新打开浏览器一定回到英文；
只有用户显式选择，或在同一会话内保持，才会显示其它语言。

### 切换器中的语言名称

`settings.LANGUAGES` 保存的是每种语言的**母语名称**，且刻意**不要**用
`gettext_lazy` 包裹。因为 `{% get_available_languages %}` 会再做一次翻译 ——
Django 自带目录会把 `English` 翻成 `英语`、`Anglais`，所以切换器遍历的是
`apps.core.context_processors.languages` 提供的 `AVAILABLE_LANGUAGES_NATIVE`。
今后任何语言列表都应使用该变量（或直接使用 `settings.LANGUAGES`）。

代码中切换语言：

```python
from django.utils import translation
translation.activate('zh-hans')
```

## 3. 新增或修改文案

1. 包裹新文案：

   ```django
   {% load i18n %}
   <h1>{% translate "预测结果" %}</h1>
   ```

   ```python
   from django.utils.translation import gettext as _     # 模型层用 gettext_lazy

   messages.success(request, _('上传成功'))
   ```

2. 重新抽取（两种语言一起）：

   ```bash
   python manage.py makemessages -l en -l zh_Hans --ignore=".venv/*"
   ```

3. 填写 `locale/en/LC_MESSAGES/django.po` 中的英文 `msgstr`，
   并把新增 `msgid` 同步写入 `locale/zh_Hans/LC_MESSAGES/django.po` 的 `msgstr`
   （恒等映射，可用下面的脚本自动完成）：

   ```bash
   python scripts/sync_zh_catalog.py
   ```

4. 编译并验证：

   ```bash
   python manage.py compilemessages
   python manage.py runserver   # 切换语言检查新文案
   ```

## 4. 新增一门语言

1. 在 `config/settings.py` 的 `LANGUAGES` 中加入该语言的**母语名称**，且不要包
   `gettext_lazy`，例如 `('ko', '한국어')`。
2. `python manage.py makemessages -l ko --ignore=".venv/*"`
3. 翻译 `locale/ko/LC_MESSAGES/django.po`（308 条）。
4. `python manage.py compilemessages`
5. 该语言会自动出现在切换下拉框中。

## 5. 本地化日期

`strftime()` 生成的永远是 `2025-01` 这种语言无关格式，所以中文界面下日期看起来
仍然是"英文式"的数字。模板应使用 `apps/core/templatetags/i18n_dates.py` 的过滤器：

```django
{% load i18n_dates %}
{{ item.date|localize_date }}    {# 2025年1月15日 · Jan. 15, 2025 · 15 janvier 2025 #}
{{ month|localize_month }}       {# 2025年1月 · January 2025 · janvier 2025 #}
```

`localize_date` 使用当前语言的 `DATE_FORMAT`，`localize_month` 使用当前语言的月份名，
两者都依赖 Django 自带目录，月份名已经翻译好。年月组合格式本身也可翻译，
msgid 为 `#year#年#month_num#月`（英文 `#month_name# #year#`，
日文 `#year#年#month_num#月`）；这里用 `#…#` 而不是 `{}`，否则 `msgfmt`
会把该条目当作 brace format 校验而报错。

需要回传给服务端的值（`<input type="date">` 的 `value`、被 JS 读取的 `data-*`
属性等）仍要保持 ISO 格式（`|date:"Y-m-d"`）。

## 6. 两个坑

**百分号。** `django.utils.translation.template.templatize()` 在从模板抽取文案时会把
`%` 转义成 `%%`，导致目录里的键是 `%%`、运行时的字符串是 `%`，永远匹配不上。
请把字面百分号放在标签**外面**：

```django
{# 错误：目录里的键会变成 "变化%%" #}
{% translate "变化%" %}

{# 正确 #}
{% translate "变化" %}%
```

属性值和内联 JavaScript 中同样适用。

**JavaScript。** `<script>` 里的文案在服务端翻译，且必须位于字符串字面量内部：

```javascript
alert('{% translate "请选择销售区域" %}');
```

只翻译字符串字面量，绝不要把语句或注释包进去。

## 7. 贡献者检查清单

* [ ] 新增界面文案已用 `{% translate %}` / `gettext()` 包裹
* [ ] `makemessages` 覆盖了**全部**语言（`en zh_Hans fr de es ja`）
* [ ] 英文 `msgstr` 已填写，中文目录已重新同步，其它目录已更新
* [ ] 已执行 `python manage.py compilemessages`
* [ ] 页面已在英文与中文下检查；日期使用 `|localize_date` / `|localize_month`
* [ ] `{% translate %}` 标签内没有字面 `%`
